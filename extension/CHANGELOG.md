# Folio Markdown Editor changelog

## 0.1.0 release candidate

- Open Markdown files in the optional Visual, Source, and Split editor with VS Code Save and Undo/Redo.
- Use native Folio commands and themes, preview existing workspace raster images, and follow workspace Markdown links.
- Browse existing images in supported local Windows NTFS workspaces and insert portable Markdown references. A cancelled or undecodable replacement preserves the previous valid selection for revalidation when you insert it.
- Review pending Markdown after a conflict or interruption. Folio keeps both recovery copies and prompts for manual reconciliation.
- The VSIX includes third-party notices for bundled webview dependencies and declares its Workspace Trust requirement.
- Added EPL 1.0 text and source references for components compiled into Mermaid's ELK runtime, plus attribution for dependencies whose license text was missing from the generated inventory.
