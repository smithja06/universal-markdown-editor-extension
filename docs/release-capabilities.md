# Folio first-release capability matrix

This matrix tracks the approved first-release scope across standalone Folio and the VS Code extension. Phase 6 qualified the Windows Markdown checkpoint. Phases 7A and 7B added standalone TXT and DOCX. Phase 7C added native TXT and the DOCX draft and reviewed-copy workflow in VS Code. Public GitHub and Marketplace releases require qualified Markdown, TXT, DOCX, PDF, and XLSX workflows, completion of the applicable release capability scope, the distribution review, and explicit authorization. CSV is also in the Phase 9 scope. [Project handoff](PROJECT_HANDOFF.md) · [Distribution requirements](extension-distribution.md#requirements-and-release-decision)

**Implemented** means the scoped workflow exists on the stated host. **Partial** means the current workflow covers part of the capability. **Planned** identifies work with a target phase. **Blocked** identifies a prerequisite that must be resolved before enabling the capability. A capability status alone does not certify a release artifact or additional platforms.
